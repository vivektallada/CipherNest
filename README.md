# 🔐 CipherNest

### Secure File Encryption & Decryption

CipherNest is a web-based file encryption and decryption
application that protects files using AES-256-GCM encryption.

## Features
- AES-256-GCM Encryption
- Password-based protection
- PBKDF2-SHA256 key derivation
- File encryption and decryption
- Password strength indicator
- Local browser-based processing
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Web Crypto API

## Security
- AES-256-GCM
- PBKDF2-SHA256
- 600,000 iterations
